# 8. Conclusiones

El desarrollo del proyecto Code_Craft permitió aplicar de manera práctica los conocimientos adquiridos en el programa de Análisis y Desarrollo de Software, integrando las fases de planificación, diseño, desarrollo, pruebas y documentación bajo una metodología estructurada.

---

## Conclusiones Generales

- Cumplimiento de Objetivos:
El sistema Code Craft logró cumplir los objetivos planteados, ofreciendo una plataforma funcional para la gestión, seguimiento y desarrollo de proyectos web de manera colaborativa entre clientes y desarrolladores.

- Arquitectura Eficiente:
La arquitectura Cliente-Servidor, implementada con React.js en el frontend, Node.js y Express.js en el backend, y PostgreSQL como base de datos, garantizó un entorno escalable, seguro y de fácil mantenimiento.

- Diseño Centrado en el Usuario:
Gracias al enfoque UX/UI, se desarrolló una interfaz intuitiva, visualmente coherente y adaptable a distintos dispositivos, mejorando la experiencia del usuario y la accesibilidad del sistema.

- Control de Calidad:
A través de las pruebas funcionales, de interfaz, seguridad y rendimiento, se aseguró que el producto final fuera estable y confiable, con una tasa de errores mínima y desempeño óptimo.

- Trabajo Colaborativo:
La distribución de roles dentro del equipo de desarrollo permitió una gestión eficiente de las tareas, fomentando la comunicación, la revisión constante y la mejora continua del producto.

---

## Impacto del Proyecto

Code_Craft se consolida como una herramienta que puede ser utilizada por empresas o equipos de desarrollo para optimizar el ciclo de vida de sus proyectos web, integrando seguimiento, asignación de tareas, evaluación de desempeño y comunicación entre los diferentes actores del proceso.

Su diseño modular y adaptable permite futuras mejoras, como la incorporación de analítica de proyectos, integración con servicios en la nube y automatización de pruebas.

---

## Trabajo Futuro

- Implementar autenticación mediante OAuth (Google / GitHub).
- Añadir métricas de desempeño y paneles analíticos en tiempo real.
- Incluir notificaciones automáticas vía correo electrónico o chat interno.
- Migrar la arquitectura hacia microservicios para mayor escalabilidad.
- Mejorar la experiencia móvil con una Progressive Web App (PWA).

---

## Conclusión Final

El desarrollo de Code_Craft demostró la importancia de aplicar buenas prácticas en ingeniería de software, destacando la colaboración, la planificación y el aseguramiento de la calidad como pilares fundamentales para la creación de productos tecnológicos exitosos.
