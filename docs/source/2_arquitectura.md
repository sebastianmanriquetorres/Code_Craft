#  2. Arquitectura del Sistema

El proyecto **Code_Craft** se desarrolla bajo una arquitectura **Cliente-Servidor**, compuesta por los siguientes elementos:

- **Frontend:** Desarrollado con React.js, encargado de la interfaz de usuario.
- **Backend:** Implementado en Node.js con Express.js, encargado de la lógica del negocio.
- **Base de Datos:** PostgreSQL, base de datos NoSQL que almacena usuarios, proyectos y configuraciones.
- **Control de versiones:** Git y GitHub, usados para el control y despliegue del código.
