# Proyecto Code Craft


Este repositorio implementa el PSP (Personal Software Process) con el objetivo de mejorar la planificación, la calidad y la productividad personal durante el desarrollo del proyecto Code Craft.

El propósito principal es desarrollar una disciplina personal rigurosa que permita medir, analizar y mejorar continuamente el proceso de construcción de software.

 Contenido del Repositorio (Entregables PSP)
## 1. Diagnóstico Personal del Proceso (PSP0 / PSP0.1)

Incluye:

- Descripción del proceso personal actual

- Diagrama de flujo del proceso

- Fortalezas y debilidades

- Estándares iniciales de código

- Primer Plan de Mejora Personal (PIP)

 

## 2. Método PROBE – Estimación del Tamaño y Esfuerzo (PSP1 / PSP1.1)

Incluye:

- lasificación de componentes por categorías (proxy)

- Estimación de tamaño (LOC)

- Comparación con proyectos previos

- Cálculo de distribuciones

- Regresión lineal PROBE

- Estimación del esfuerzo total



## 3. Métricas y Análisis Estadístico del Proceso (PSP2)

Incluye:

- Productividad (LOC/hora)

- Densidad de defectos

- Tiempo invertido por fase

- Precisión de estimaciones

- Gráficos generados (matplotlib / Excel)

- Análisis de variaciones y causas



## 4. Herramientas Digitales usadas en el PSP

Documentación del uso de:

- Clockify / Toggl — Registro de tiempo

- GitHub Issues — Seguimiento de defectos

- Trello — Trazabilidad de tareas

- Excel / Google Sheets — Métricas y estadísticas

- PSP Forms — Registro disciplinado del proceso



## 5. Postmortem y Plan Personal de Mejora (PPIP)

Incluye:

- Análisis final del proceso

- Registro de defectos más frecuentes

- Reflexión de desempeño

- Acciones concretas de mejora

- vNueva versión del proceso personal



## Objetivo del PSP aplicado a Code Craft

- El PSP se implementa en este proyecto para:

- Mejorar la exactitud en las estimaciones

- Reducir defectos desde fases tempranas

- Tomar decisiones guiadas por datos reales

- Fortalecer la responsabilidad y autogestión del desarrollador

- Aumentar la calidad del software entregado

- Este repositorio sirve como evidencia del proceso completo desde PSP0 hasta PSP2.1.
