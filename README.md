# Proyecto Code Craft


Este repositorio implementa el PSP con el objetivo de mejorar la planificación, 
la calidad y la productividad personal del desarrollo. 

Incluye:
- Estimaciones PROBE
- Registros de tiempo (supabase)
- Seguimiento de defectos (GitHub Issues)
- Métricas de productividad
- Documentación PSP (Sphinx)
- PPIP (Personal Process Improvement Plan)

El propósito principal es desarrollar una disciplina personal rigurosa que permita
mejorar continuamente el proceso de construcción de software.
